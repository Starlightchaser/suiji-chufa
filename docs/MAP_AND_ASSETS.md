# 地图与界面素材

## 世界底图

世界陆地使用Natural Earth的`ne_110m_land`数据，采用公共领域条款。来源：[数据仓库](https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_land.geojson)、[使用条款](https://www.naturalearthdata.com/about/terms-of-use/)。

## 国内边界与点位

国内行政边界保留[DataV](https://datav.aliyun.com/portal/school/atlas/area_selector)来源，由访问者浏览器从[官方接口](https://geo.datav.aliyun.com/areas_v3/bound/100000_full.json)直接加载，仓库与Pages发布包不包含这份边界数据。请求不携带本站收藏、笔记或登录凭据，并关闭来源页面引用信息。官方接口不可用时，页面保留卡片和世界陆地背景，提供重试入口。

直接加载不代表取得了数据再分发、商用或地图审查授权；本仓库不向第三方转授这些权利，后续使用需核对供应商条件及适用要求。

世界陆地、中国边界与目的地点位共用Web Mercator投影和等比视口。目的地点位为城市或县城中心的近似位置。

## 实景照片

28张目的地照片逐图保留作者、来源和对应许可。原图文件保持不变，页面使用容器裁切；请按[逐图署名](PHOTO_CREDITS.md)使用，不将全部照片统一标为MIT许可。

## 纸卡

四款纸卡底材依据项目参考稿，通过生成式图像编辑重建为透明PNG，供页面叠加独立文字和照片。纸卡用于界面装饰，不用于表达真实地理形状。

项目代码、第三方地理数据、照片及界面素材的许可分别说明；代码许可证不替代第三方素材使用条件。
